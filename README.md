## 📌 Sobre o Projeto

O UOLha Isso é uma aplicação web criada para reunir e exibir as fotoreportagens produzidas pela turma em um trabalho da disciplina de Português. O projeto busca proporcionar uma experiência interativa e organizada para visualização das reportagens.

A plataforma permite:

✅ **Criação e Exibição** das fotoreportagens  
✅ **Interface responsiva e acessível**

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- React.JS
- TypeScript
- TailwindCSS
- Next.JS
- Node.JS
- Prisma
- UploadThing
